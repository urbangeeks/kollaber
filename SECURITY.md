# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| latest  | yes       |

Kollaber is currently pre-1.0. Only the latest release receives security updates.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Email: jnixon55@gmail.com

Include as much of the following as possible:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

You can expect an initial response within 48 hours. If the vulnerability is confirmed, a fix will be prioritized and you will be credited in the release notes unless you prefer to remain anonymous.
